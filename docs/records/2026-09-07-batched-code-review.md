## 本轮复现并修复

| 问题 | 修复与证据 |
| --- | --- |
| 读取目录树只校验相交，可越出提供方范围 | Go 与 Python 都改为完整覆盖校验，拒绝更宽目录、文件冒充目录树及未排除的子路径；先复现失败，再通过领域及跨语言回归 |

| `path_absent` 把悬空符号链接视为不存在 | 同时检查 `test -e` 与 `test -L`；用真实临时链接先复现，再验证阻断 |
