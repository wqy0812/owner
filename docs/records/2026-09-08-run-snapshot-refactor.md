## 迁移与切换演练覆盖

迁移测试从精确旧合同测试库开始，执行预检、绑定源摘要、写入独立目标、验证 ready 报告和重新启动 Store。覆盖成功、失败、中断、拒绝、取消记录，三种场景模式、场景测试、关联场景的环境回滚、Generation、安装备份/Previous、恢复回执、续跑链、提交身份、清理记录、原作业包和归档字节哈希，以及 rowid/序列保留。

坏字段、缺失/错误类型、孤立场景控制字段、活动任务、错误合同、缺失表、输出路径冲突、取消和源摘要变化均拒绝发布目标。迁移后对源库、目标库、独立源备份或归档做篡改，验证入口均拒绝接受。源文件始终只读；测试验证失败不改变源库。

切换沙箱验证程序/数据库成套替换、二次源绑定检查及切换前恢复；新程序开始启动后，失败或中断保留新库，不自动恢复旧库。这些都是测试库和脚本沙箱演练。
